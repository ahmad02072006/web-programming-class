# Week 3 Friday — CSS Advanced: Practice Exercises

Solutions for the 7 practice exercises from the *CSS Advanced — Week 3 Friday Study Guide*
(K0126002 · Web Programming · Gachon University). Each exercise is a single self-contained
`.html` file — open any of them directly in a browser to see the result.

| File | Exercise | Topic | Difficulty |
|---|---|---|---|
| `exercise-1-position-badge.html` | E1 | `position: relative` / `absolute` | Beginner |
| `exercise-2-hover-card.html` | E2 | Transitions on hover | Beginner |
| `exercise-3-loading-spinner.html` | E3 | `@keyframes` animation | Intermediate |
| `exercise-4-css-variables-theme.html` | E4 | CSS custom properties + dark mode | Intermediate |
| `exercise-5-fixed-nav-bar.html` | E5 | `position: fixed` + Flexbox nav | Intermediate |
| `exercise-6-responsive-grid.html` | E6 | CSS Grid, `::before`, media queries | Advanced |
| `exercise-7-portfolio-page.html` | E7 | All techniques combined (portfolio page) | Advanced |

**Note:** Exercise 7 uses placeholder text (`YOUR NAME`, `[Your Major]`) — replace these with
your own name and major before submitting/pushing.

## How to view
Just open any `.html` file in a browser, or use a live server extension in VS Code
(e.g. "Live Server") for auto-reload while editing.
